# Responsive Login/Signup Page with Validation

This project implements a responsive and modern **Login/Signup** page with basic **email and password validations** using **HTML**, **CSS**, and **JavaScript**. The UI dynamically switches between login and signup forms, with smooth transitions and professional design.

## Live Demo : -

## Features:
- **Responsive design** for mobile, tablet, and desktop screens.
- **Email validation**: Ensures a valid email format for both login and signup.
- **Password validation**: Ensures passwords are at least 6 characters long.
- **Form switcher**: Easy toggle between login and signup forms.
- **Clean, modern UI**: Professional design with hover effects, transitions, and input focus states.

## Technologies Used:
- **HTML** for structuring the page.
- **CSS** for styling, including a clean, modern, and responsive design.
- **JavaScript** for basic form validation and toggling between login and signup forms.
